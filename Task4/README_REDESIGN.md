# Task4 — Animated College Explorer Redesign

This version keeps the original Django routing and database structure, while replacing the page presentation with a responsive animated UI.

## Included visual upgrades
- Glassmorphism cards and panels
- Animated gradient glow/orbs
- Animated grid background
- 3D mouse-follow card tilt on desktop
- Hover shine and neon glow effects
- Scroll reveal animations
- Responsive mobile layout
- Consistent navigation between Home, SISTec, LNCT and OIST
- Existing static campus images reused

## Run
1. Open the `Task4` folder in VS Code.
2. Activate your Django virtual environment.
3. Run:
   `python manage.py runserver`
4. Open:
   `http://127.0.0.1:8000/`

## Note
The redesigned pages use the existing Django URL names: `main`, `sistec`, `lnct`, and `oist`.
